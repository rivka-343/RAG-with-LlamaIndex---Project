# My Librory

ספרייה חכמה לבחינת שאלות ושאילתות על מאגר ספרים באמצעות AI, RAG ו-vector search.

## תיאור הפרויקט

My Librory הוא פרויקט Python שמטרתו לאפשר חיפוש ושאלות על קטלוג של ספרים באמצעות מודל שפה (LLM) ו-AI Retrieval-Augmented Generation (RAG). המערכת מעבדת נתוני ספרים, יוצרת ייצוגים וקטוריים, ושומרת אותם במסד נתונים וקטורי מקומי כדי לאפשר חיפוש סמנטי ורלוונטי.

המטרה המרכזית היא לספק ממשק אינטראקטיבי שבו המשתמש יכול לשאול שאלות בשפה טבעית על ספרים, מחברים, נושאים וקישורים, ולהקבל תשובות מבוססות על מאגר הנתונים המקומי.

## תכונות עיקריות

- עיבוד נתוני ספרים מתוך קובץ CSV
- יצירת טקסט מאוחד לכל ספר עם מטא-דאטה
- אינדקס וקטורי באמצעות ChromaDB
- שימוש ב-embeddings ליצירת חיפושים סמנטיים
- שילוב עם Gemini API עבור תשובות חכמות
- ממשק צ'אט פשוט בעברית
- אחסון מקומי של האינדקס לטעינה מהירה

## טכנולוגיות בשימוש

- Python 3.13+
- Gemini API
- LlamaIndex
- ChromaDB
- Pandas
- Sentence Transformers
- python-dotenv

## התקנה

1. Clone the repository

```bash
git clone <repository-url>
cd my_librory
```

2. התקן את התלויות

```bash
python -m pip install -e .
```

3. צור קובץ `.env` בתיקיית הפרויקט עם המפתח הבא:

```env
GEMINI_API_KEY=your_api_key_here
```

## הפעלה

### 1) יצירת אינדקס וקטורי

```bash
python rag/build_index.py
```

פקודת זה תטעין את קובץ ה-CSV, תעבד את הרשומות, תיצור vectors, ותשמור אותם בתיקיית `chroma_db`.

### 2) הפעלת הצ'אט

```bash
python main.py
```

לאחר מכן תוכל להזין שאלות בעברית, לדוגמה:

- אילו ספרים עוסקים בתכנות?
- מי כתב את הספר X?
- מהן ההמלצות בנושא יהדות?

### 3) בדיקת מודלים זמינים

```bash
python a.py
```

הפקודה בודקת אילו מודלים זמינים למפתח ה-Gemini.

## זרימת עבודה

1. הנתונים נקראים מקובץ CSV.
2. כל שורה מומרת למסמך מאוחד עם פרטי ספר.
3. ה-data נשלח ל-embedding model כדי ליצור vectors.
4. ה-vectors נשמרים ב-ChromaDB.
5. בעת שאלת משתמש, המערכת מחפשת את המסמכים הרלוונטיים ביותר.
6. התשובה נוצרת באמצעות Gemini ומוצגת למשתמש.

## דוגמה לזרימת ריצה

```text
משתמש: אילו ספרים עוסקים במחשב?
→ המערכת מחפשת ב-vectors רלוונטיים
→ בוחרת את הספרים המתאימים ביותר
→ שולחת את הנתונים ל-Gemini
→ מחזירה תשובה בעברית עם המלצות / מידע
```

## הערות

- דוגמת קובץ הנתונים היא `rag/otzar_books.csv`.
- מסד הנתונים הווקטורי נוצר אוטומטית בתיקייה `chroma_db`.
- חשוב לוודא שה-API key מוגדר כראוי בקובץ `.env` לפני הפעלה.
